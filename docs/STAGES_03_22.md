## تنفيذ مبدئي ضمن المرحلة الحالية
- تمت محاولة إصلاح CI الذي تعطل بسبب sdkmanager package 'tools'؛ النجاح غير مثبت بعد.
- أضيفت شاشة تصفح موضوعات أحكام الجنائز بمحتوى **مسودة غير معتمد**.
- أضيف مسار تنقل ثالث؛ لم يختبر على هاتف بعد.
- بقيت جميع معايير القبول الأخرى مفتوحة.

## بوابات الجودة
1. لا يُدمج كود Android دون CI ناجح.
2. لا يُنشر حكم شرعي معتمد دون مراجعة بشرية موثقة.
3. لا يُنشر ملف صوتي دون ترخيص استخدام محدد.
4. لا تُفعّل خدمات موقع أو بيانات أسر دون موافقات وصلاحيات وتدقيق.
5. لا يُعلن نجاح اختبار الجهاز دون سجل موثق.
