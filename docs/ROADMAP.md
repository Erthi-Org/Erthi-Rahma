# خارطة الطريق

## Stage 1 — أساس Android
- Kotlin / Compose، RTL، شاشة رئيسية، ملاحة، تصميم، اختبارات وحدة، Gradle Wrapper، CI.
- معيار القبول: بناء Debug ناجح في CI؛ التحقق الفعلي على هاتف مستقل لاحقًا.

## Stage 2 — صانع النعي Offline
- إدخال معلومات، قوالب محلية، معاينة PNG، مشاركة، حفظ دون رفع.
- معيار القبول: إنشاء ومشاركة صورة دون إنترنت، واختبار نصوص طويلة.

## Stage 3 — التعليم الشرعي
- نموذج محتوى مع مصادر وإصدارات ومراجعة بشرية، ثم الحزمة المحلية.
- معيار القبول: ألا يظهر درس بوسم اعتماد قبل توثيق المراجع والمراجع الشرعي.

## Stage 4 — الخريطة والجهات
- Laravel, PostgreSQL/PostGIS، البحث المكاني، طلبات التوثيق، لوحة مشرف.
- معيار القبول: نتائج من سجل تجريبي معلّم بوضوح، وحدود عرض البيانات العامة.

## Stage 5 — شبكة المساعدة
- تسجيل متطوعين، إسناد طلبات، إشعارات، منع الإساءة، أوقات توافر.
- معيار القبول: دورة طلب كاملة واختبارات صلاحيات وإلغاء/انتهاء.

## Stage 6 — إطلاق تجريبي داخل مصر
- اختبار Android فعلي، أمان، قانوني، شرعي، وصولية، موافقات وخصوصية.
- معيار القبول: لا عيوب حرجة، وبيانات جهات موثقة، ومراقبة البلاغات.

## الأوامر الإجرائية
- التغييرات على فرع feature أو development.
- فتح Pull Request قبل الدمج إلى main.
- لا تصف أي اختبار بأنه ناجح إلا بوجود سجل CI أو اختبار موثق.
- لا إصدار APK على أنه جاهز قبل توقيع مناسب، اختبار جهاز، وفحص خصوصية.
