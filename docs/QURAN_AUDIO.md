# الاستماع إلى القرآن الكريم — متطلبات المنتج

## الوظائف
- قائمة سور كاملة مع بحث عربي.
- اختيار قارئ ورواية ونوع التلاوة عند توفر بيانات موثوقة.
- تشغيل وإيقاف وتقديم وتأخير وتكرار السورة.
- تشغيل في الخلفية مع MediaSession وإشعار تحكم وشاشة القفل.
- حفظ آخر سورة وموضع تشغيل محليًا.
- تحميل للاستماع دون إنترنت فقط إذا أجاز ترخيص الملف التخزين وإعادة التوزيع.
- اختيار جودة الصوت لتقليل استهلاك البيانات.

## معايير حقوق النشر
- صوت التلاوة وتسجيلها لهما حقوق مستقلة عن النص القرآني.
- لا تُنسخ ملفات من مواقع أو تطبيقات دون ترخيص صريح مناسب.
- يجب حفظ المصدر وحقوق التسجيل وقيود البث والتخزين والتنزيل لكل ملف.
- لا يُفعّل تنزيل ملف دون تحقق حق تنزيله وإعادة إتاحته.
- ينبغي التحقق من سلامة الملفات وترتيب الآيات وعدم قطع التسجيلات.

## المعمارية الحالية والاختبارات المتبقية
- نُفذ Android Media3 ExoPlayer + MediaSessionService وحفظ آخر تسجيل وموضعه محليًا.
- Catalog API اختياري للمصادر المصرح بها.
- المسودات محفوظة في Room؛ موضع التلاوة في SharedPreferences. التنزيلات ملفات محلية في noBackupFilesDir، بحد 512 MiB للملف و1 GiB إجمالًا.
- اختبارات انقطاع الاتصال، المكالمات، Bluetooth، قفل الشاشة، واستعادة التشغيل.

## ملاحظة شرعية
المصحف للاستماع والتعلم العام؛ لا يخصص التطبيق تلاوة سورة أو تشغيلًا عند الوفاة باعتبار ذلك سنة ثابتة دون دليل ومراجعة.


## التحقق الحالي وحدوده

- المصدر المعرّف في الكود هو CDN الخاص بـ AlQuran.cloud؛ لم تُضف تسجيلات صوتية إلى المستودع.
- نُفذت واجهة بحث السور والتشغيل/الإيقاف المؤقت والتنزيل والحذف، وخدمة خلفية مع MediaSession وحفظ الموضع. اختيار جودة الصوت والتقديم/التأخير والتكرار ليست مكتملة في الواجهة الحالية.
- الوثيقة السابقة كانت تصف نسخة أقدم قبل إضافة Media3 والتنزيلات والطبلاوي وفارس عباد؛ لا تستخدم لتحديد حالة التنفيذ الحالية.
- عند `1e613fbc58d3f849b2e97faf72612b55c2ff83b0` نجح البناء واختبارا التنقل ومرحلتان منفصلتان لاختبار حفظ المسودة وموضع التلاوة بعد إيقاف العملية على كل من API 26 و35: https://github.com/Erthi-Org/Erthi-Rahma/actions/runs/43363657403
- اختبارات الموضع تكتب حالة اختبار محلية؛ لا تشغل بثًا صوتيًا ولا تثبت استمرار الصوت في الخلفية أو استعادته الفعلية.
- تشغيل ملفات المزود وقفل الشاشة والمكالمات وBluetooth والتنزيلات على هاتف فعلي لم تتحقق بهذه الاختبارات.
- لم تُنفذ مراجعة حقوق جديدة في هذه الجولة. يلزم توثيق حقوق البث والتنزيل لكل تسجيل قبل اعتماد النشر العام؛ وجود رابط أو عبارة في الواجهة لا يثبت الموافقة.
