# متطلبات إرثي رحمة

## الهدف
مساعدة أهل المتوفى على إنشاء النعي وفهم الخطوات الشرعية والعثور على خدمات جنائز تم التحقق منها؛ الإطلاق الأول لمصر، الواجهة عربية RTL.

## الشخصيات
- زائر: قوالب النعي والمحتوى التعليمي والدليل العام.
- ممثل الأسرة: نشر نعي اختياري وطلب خدمة وإدارة البيانات.
- مغسل/مغسلة أو متطوع: تسجيل ملف مهني وتوفره، لا يظهر إلا بعد التحقق.
- مسؤول مسجد أو جمعية: تسجيل مقر وخدمات وتحديثها.
- مراجع شرعي: مراجعة الدروس وإصداراتها ومراجعها.
- مشرف: تحقق وبلاغات ومراجعة تغييرات وسجل تدقيق.

## قصص المستخدم ومعايير قبول
### P0 — النعي المحلي
- اختيار قالب وتحرير الاسم وتاريخ الوفاة والدعاء والموعد الاختياري، مع صيغة مناسبة للجنس.
- معاينة وتصحيح البيانات، وتوليد PNG دون إنترنت، ومشاركة Android Sharesheet دون رفع البيانات.
- لا يُلزم حساب ولا يُنشر رابط عام تلقائيًا.
- اختبار RTL والقصّ الطباعي مع أسماء طويلة.

### P0 — التعليم
- دروس الغسل والتكفين والصلاة والدفن منفصلة مع المراجع وحالة المراجعة.
- إظهار الخلاف الفقهي المعتبر عند وجوده؛ لا اعتماد دون مراجعة شرعية.
- دعم القراءة دون إنترنت للمواد الموافق عليها.

### P0 — دليل الخدمات
- البحث الجغرافي عبر إذن موقع اختياري أو اختيار محافظة/مدينة يدويًا.
- فلترة: غسل / كفن / خدمات دفن / جمعيات؛ توثيق الجهة، التكلفة، مواعيد الاتصال، آخر تحديث.
- إظهار الفرق بين مجاني مؤكّد، مجانية غير مؤكدة، مدفوع أو غير معروف.
- لا تصنيف للمقابر المجانية دون إثبات الجهة المخوّلة وشروط الاستحقاق.

### P0 — التسجيل والتحقق
- تسجيل مسجد/جمعية/متطوع مع أقل قدر لازم من البيانات والمستندات، وتدقيق قبل النشر.
- فصل دور المسؤول والمراجع عن المعلن؛ إيقاف الحساب والبلاغات وإعادة التحقق الدوري.

### P1 — المساعدة
- إنشاء طلب بخدمة ومنطقة ووسيلة اتصال خاصة، ثم إسناد ومتابعة وإلغاء.
- لا تظهر التفاصيل الشخصية للزائر؛ لا ضمان توافر المتطوع فورًا.
- الاتصال المباشر بالطوارئ أو بالجهة المختصة وفق الحالة خارج التطبيق.

### P1 — صفحة المتوفى
- نشر اختياري بتفويض مسؤول من الأسرة، وصلاحية تعديل/حذف وإبلاغ عن إساءة أو انتحال.

## غير مشمول حاليًا
- دفع/جمع تبرعات داخل التطبيق.
- اعتماد مغسل أو فتوى آليًا.
- الإبلاغ الرسمي عن الوفاة أو استخراج تصاريح دفن.
- وعد توافر مقابر أو خدمات فورًا دون جهة مؤكدة.
