# إرثي | رحمة — Erthi Rahma

تطبيق أندرويد إسلامي خيري مفتوح المصدر، يهدف إلى تيسير خدمات الجنائز، وصناعة النعي ومشاركته، وتوفير دليل موثوق لغسل الميت وتكفينه وصلاة الجنازة والدفن، وإتاحة البحث عن الجهات والمتطوعين الذين يقدمون المساعدة.

**المبادرة:** إرثي — مستقلة عن أي علامة تجارية أخرى.  
**النطاق الأول:** مصر، باللغة العربية (RTL).  
**الحالة:** التخطيط والتأسيس الهندسي؛ لم يُنشر APK أو Backend بعد.

## نطاق المشروع

1. إنشاء قوالب نعي محلية دون تسجيل أو إنترنت، وتصدير PNG ومشاركة آمنة.
2. مكتبة تعليمية شرعية؛ لا ينشر المحتوى بوصفه معتمدًا حتى مراجعته من مختص.
3. دليل جغرافي للخدمات: المغاسل والأكفان والمساعدات المتعلقة بالمقابر والدفن.
4. تسجيل وتوثيق المساجد والجمعيات والمغسلين والمتطوعين.
5. طلبات مساعدة تحمي خصوصية أهل المتوفى، دون وعود غير موثقة بالتوافر الفوري.
6. صفحات تذكارية اختيارية، مع موافقة الأسرة والتحكم في النشر والحذف.

## التقنية المقترحة

- Android: Kotlin / Jetpack Compose / Room، Offline-first للقوالب والمحتوى المعتمد.
- Backend: Laravel REST API.
- Data: PostgreSQL / PostGIS.
- Maps: OpenStreetMap عبر مكتبة متوافقة مع الترخيص.
- Notifications: FCM عند توفر الخدمة، مع بدائل اتصال مباشرة.
- CI: GitHub Actions لبناء واختبار Android؛ لا يعتبر النجاح الآلي إثباتًا للاختبار على جهاز فعلي.

## مبادئ لا تُستثنى

- التطبيق خيري ومجاني، ولا يبيع بيانات المستخدمين.
- لا تُنشر بيانات متوفى أو صورة أو تفاصيل عزاء علنًا دون تفويض مناسب.
- لا يُعلن عن خدمة مجانية أو جهة معتمدة قبل التحقق.
- بيانات الاتصال الحساسة لا تعرض للعامة دون موافقة، ولا تُحفظ إحداثيات المتطوع الخاصة بشكل مكشوف.
- لا تعد دروس التطبيق بديلًا عن المختصين في الغسل أو الجهات الشرعية والقانونية.
- مراجعة قواعد حماية البيانات المصرية وشروط تقديم الخدمات قبل التشغيل الفعلي.
